# Discriminating tests

Testing is allowed whenever the phase permits the claim. Phase 1 checks extraction, Phase 2 source identifications, Phase 3 clustering, Phase 4 internal order, and later phases broader structure. A test cannot create a claim forbidden by that phase.

1. Pick one proposition and revision. State its strongest serious alternative, including a literal reading when relevant.
2. Predict observable differences: exact continuation, date/time consistency, viewpoint, location, object state, source passage or event consequence. Explain which outcomes favor which alternative before looking.
3. Inspect the specified evidence within source policy. Record T ID, explicit `claim_revision`, prediction, procedure, V IDs and outcome (`supported`, `contradicted`, `inconclusive`). In Phase 1, record observation checks in Notes; T records require an existing permitted C claim.
4. Contradiction triggers rejection or suspension and downstream dependency review. Support increases only when new independent evidence or a discriminating result excludes a serious alternative. Finding no contradiction is not a confirmation and never earns an automatic increment.
5. After two distinct inconclusive tests, suspend the claim with a precise reopening condition and work on another uncertainty. Rerunning the same search is not another independent test. Return to research/clustering through the authorized phase loop if the missing evidence is structural.

Ordering tests assess specific accepted constraints and affected neighbor joins. They do not optimize lexical totals. No repeated words at a boundary can be entirely compatible with a valid scene/narrator change; several common phrases can coexist with an impossible transition. A restitch is justified by constraints and alternatives, never by reducing zero-match boundaries.

Phase 6 challenges the whole proposed order and distinct event/identity claims under the final gate. A complete draft and six rows are not evidence of correctness.
