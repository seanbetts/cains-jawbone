# Workflow regression scenarios

These synthetic cases test instruction application without importing puzzle progress. Baseline failures were recorded in the approved workflow audit before revision; they are evidence of the old procedures, not a new measured agent trial. Repeat these scenarios against future edits.

| Scenario | Old failure or gap | Required decision under v2 |
|---|---|---|
| A rearrangement removes three zero-match joins but lacks narrative evidence. | Lexical-score adoption rule favored it. | Do not adopt on counts; identify affected typed constraints and inspect actual transitions. |
| A three-word phrase appears in two pages, in either direction. | Correlated words/ngrams counted as several anchors. | One recurrence is retrieval evidence; no direction or adjacency follows. |
| A source search finds the author for half a compound question, leaving a name unexplained. | Existing resolved labels concealed unresolved parts. | partial, or split the question; verified applies only to fully supported questions. |
| An exact search snippet names a plausible poem but the passage cannot be opened. | No machine-readable distinction for passage read. | candidate, snippet_only, exact location/verification next step; no verified attribution. |
| A Phase 4 ordering claim has a testable contradiction. | Falsification skill disallowed Phases 1–5. | Test now, record outcome and suspend/reject affected claims as warranted. |
| A page matches no existing narrator; its borrowed verse resembles another page. | New narrator created on non-match. | Keep unassigned page signature; separate quote layer; seek positive voice evidence. |
| A premise is revised after its source match fails. | Copies across indices hid provenance. | Revise the source-interpretation premise and suspend/reassess recursive consumers of stale revisions. |
| Only five distinct victim identities are supported and two event rows may describe one death. | Numeric/complete-draft pressure lacked structural enforcement. | Keep unknowns, test event/alias deduplication, block final output. |
| An odd spelling matches the archive. | Archive agreement was treated as ruling out transcription error. | It proves archive consistency only; compare an admitted authoritative image and never silently edit body. |
| Two different checks fail to distinguish narrator partitions. | Repeated rereads/scan loops could raise confidence. | Suspend with precise reopening evidence and work on another uncertainty. |
| Main has newer tool edits and the run has reviewed infrastructure fixes. | Whole-directory checkout could overwrite target work. | Review scoped commits/patches against current target; inspect hooks, preserve unrelated files, separate merge/push authorization. |
| A fresh baseline has no admitted historical sources. | Undated discovery hosts could appear sufficient approval. | Check and admit eligible editions within the approved discovery corpus before evidentiary use; empty catalog does not block admission. |

Expected answers are application checks, not proof these procedures will solve the book. State/script tests and a fresh independent solving run supply different evidence.
